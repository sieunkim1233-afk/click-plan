# 눌러보는 기획서

글로 쓴 기획서를 앱 화면으로 바꾸고, AI 팀원과 빈틈을 고치며 나에게 가까운 IT 직무를 찾아보는 진로 체험 웹 서비스입니다.

**서비스 주소:** https://click-plan.vercel.app

## 해결할 문제

기획서는 글로만 보면 완벽해 보이지만, 실제로 만들기 시작하면 "이 버튼을 누르면 어디로 가지?" 같은 빈틈이 드러납니다. IT콘텐츠 전공 학생은 기획서가 어떤 화면이 될지 미리 확인하기 어렵고, 디자이너나 개발자의 시선으로 기획을 검토해 볼 기회도 부족합니다.

## 대상 사용자

기획서를 처음 써 보거나 진로를 탐색 중인 IT콘텐츠 전공 1·2학년

## 사용 흐름

1. 체험할 프로젝트 의뢰를 고릅니다.
2. 서비스 목적, 대상 사용자, 주요 화면, 버튼 동작을 기획서로 작성합니다.
3. 기획서를 바탕으로 앱 화면 미리보기를 확인합니다.
4. AI 디자이너와 AI 개발자의 질문으로 기획의 빈틈을 찾습니다.
5. 답변을 반영해 앱 화면을 수정합니다.
6. 수정 전후 비교와 진로 체험 리포트를 확인합니다.

## 생성형 AI 활용

- 학생이 쓴 기획서를 읽고 앱 화면의 버튼 동작을 연결합니다.
- 기획서 내용을 바탕으로 AI 팀 회의 질문을 생성합니다.
- 학생의 기획서와 선택한 답변을 근거로 진로 체험 리포트를 작성합니다.
- AI 호출에 실패하면 예시 데이터로 체험이 이어지도록 구성했습니다.

## 진로 체험 리포트

이번 체험에서 자주 살핀 것, 서비스 기획·UX 디자인·프론트엔드 개발 중 가까웠던 일, 다음에 해 볼 작은 과제를 보여 줍니다. 적성을 단정하지 않고 학생의 문장과 선택을 근거로 정리합니다.

## 사용 기술

- HTML, CSS, JavaScript
- Vercel, Vercel 서버 함수
- OpenAI API

## 환경변수

- `OPENAI_API_KEY`: OpenAI API 키
- `OPENAI_MODEL`: 사용할 모델 이름

API 키는 코드에 포함하지 않고 Vercel 환경변수로만 관리합니다.
